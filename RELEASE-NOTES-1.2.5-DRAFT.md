# Historical Random Start 1.2.5 — release notes draft

## Known issue: opening trader quest after leaving the world

If you leave a Random start before finishing the starter tasks and opening **Journey to Settlement** trader visit, that quest may point to a Pine Forest trader when you return, even if your random landing was in another biome. The landing remains saved and will not repeat. For this release, finish the starter tasks and speak to the opening trader before leaving the world. If this has already happened, the quest marker can still be followed to its selected trader. Standard starts use the game's normal route.

If DEV repairs the route, replace this entry with the verified behavior. The `1.2.5-qa.002` ZIP remains frozen and unchanged.
