# Historical Random Start 1.2.5 — release notes draft

## Known issue: opening trader quest after leaving the world

If you leave a Random start before **Journey to Settlement** assigns a trader destination, that quest may point to a Pine Forest trader when you return, even if your random landing was in another biome. The landing remains saved and will not repeat. For this release, stay in the world until the trader destination appears; you can finish the trader visit later. If you have already left early, the quest marker can still be followed to its selected trader. Standard starts use the game's normal route.

This is provisional public copy for the finding in `QA-FINDING-1.2.5-qa.002-trader-route.md`. Use it on the 1.2.5 Nexus page only if release owners accept the known limitation. If DEV repairs the route, replace this entry with the verified behavior. The `1.2.5-qa.002` ZIP remains frozen and unchanged.
