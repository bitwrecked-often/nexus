# Trader-session notice prototype for the next HRS candidate

This folder contains only the two changed customer files. `p0158.ps1` is the native WinForms manager; `README.md` is its customer instructions. Both were copied from the frozen `1.2.5-qa.002` extracted package and changed only for the accepted known-issue notice and post-write confirmation flow. The frozen customer ZIP and extracted QA package remain unchanged.

For the next DEV candidate, use these files as the starting point for `dev/ui/p0158.ps1` and the customer `README.md`, then rebuild the package, manifests, receipts, and QA identity. The note appears only in the post-write Settings Applied popup for Random mode, including RandomSafe. The existing pre-write Yes/No confirmation remains. Launch Game is disabled after Yes until the verified write succeeds and the success popup closes. No success popup appears after a failed write. Returning to the manager after starting Steam refreshes Launch Game availability. Biome selection, policy writing, installation, and the launch command are unchanged.

The source parses with Windows PowerShell 5.1. The real-manager `-SmokeTest` path passed against a temporary package copy without installing or launching the game. DEV should exercise a real successful Apply, a failed Apply, and Apply while Steam is closed followed by starting Steam and returning to the manager. The post-write popup sequence must be exercised in an isolated game installation before a new candidate is exported.
