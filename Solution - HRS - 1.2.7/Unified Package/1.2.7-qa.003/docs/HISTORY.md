# Project history

These original documents explain how New Player Random Start developed under
its earlier Historical Random Start name. They retain their dates, old names,
findings and evidence boundaries. Historical options and old approval steps
are records of that period; the main package entry, current frozen contracts
and current source define this candidate.

- [Original Alpha 6 Method manifest](../history/origins/n0008.md),
  [plan](../history/origins/n0009.md) and
  [review/reasoning log](../history/origins/n0010.md): the player's intended
  experience, native integration and the narrowing to Standard/Random.
- [Original changelog](../history/origins/changes.md): the August 21 exact-name
  frontend-to-runtime vertical slice and subsequent development chronology.
- [Core execution packet](../history/origins/n0138.md) and
  [atomic semantic-preservation working paper](../history/origins/n0192.md):
  the first successful native relocation, why it had to be deferred to the
  game-update callback, and what one observation could and could not establish.
- [Early control/state model](../history/origins/n0226.md) and
  [UX evolution manifest](../history/origins/n0227.md): previous UI decisions,
  alternatives and deferred ideas.
- [Curated-start survey](../history/origins/n0230.md) and
  [arrival-biome protection design](../history/origins/n0231.md): early
  placement and protection layers.
- [How this was made](../history/HOW_THIS_WAS_MADE.md): the project's build,
  deployment, state, observability and release-engineering story.
- [1.2.4 version notes](../history/versions/1.2.4.md),
  [1.2.5 version notes](../history/versions/1.2.5.md),
  [biome-selection contract](../history/versions/BIOME-SELECTION.md),
  [trader-session notice](../history/versions/TRADER-NOTICE.md) and
  [1.2.6 native UX work](../history/versions/NATIVE-UX-1.2.6.md): the placed-world,
  selection, session-guidance and native-manager development that led here.
- [1.2.7 work manifest](../history/versions/DEV-1.2.7.md): public rename,
  picture-only logo, Game Name wording, removal of the manual Restore control
  and the four reviewed runtime/manager repairs.

[Evidence](../evidence/README.md) includes the preserved sizing failures,
historical geometry checks and the repaired candidate's bounded DEV records.
Independent customer QA remains separate and Pending until it is executed.
Original sealed records remain in the project repository. Public text copies
replace private workstation paths with portable tokens and record both the
original and public hashes; they are openly identified projections.
