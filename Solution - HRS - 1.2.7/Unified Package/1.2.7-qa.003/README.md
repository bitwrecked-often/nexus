# New Player Random Start

**7 Days to Die v3.3.0 Â· Random Player Start. By Bit Wrecked.**

Start a fresh character somewhere different. Choose a biome, let the mod pick,
or set your own weights. A supported world can be new or already generated.

Extract the complete ZIP to a writable local folder, close the game, open Steam
and run **START.bat** here. Enter your save's exact **Game Name**, choose your
settings and Apply. Acknowledge Settings Applied, then Launch Game. Random
placement happens once, on a fresh character's first spawn.

Use Windows PowerShell 5.1, local single-player and EAC disabled with the supplied
0_TFP_Harmony. The qualified target is **V3.3.0 b17**, Navezgane or supported
Random Gen worlds of 8192 or larger. Complete the opening tasks and wait for the
Journey to Settlement trader marker before leaving the first Random session.
Read [the full setup guide](customer/HistoricalRandomStart_1.2.7/README.md) for
protection, upgrades, removal and the known early-logout limitation.
