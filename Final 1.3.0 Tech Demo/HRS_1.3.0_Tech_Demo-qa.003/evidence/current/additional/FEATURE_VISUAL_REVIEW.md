The intended product is **New Player Random Start**, front label
**Tech Demo | 1.3.0**. This review settles the returned UX changes before the
full human/runtime campaign. It does not mark the formal 46 cases Pass.

Review the real root START entry from the new complete public candidate:

- Picture-only Bit Wrecked logo, light surfaces, small orange highlights and
  outlined Apply Settings. The version is visible without DEV or QA in its label.
- Game Name, including intent before a save exists. Check settings
  reads current disk files and compares the full active draft without applying,
  creating a save or claiming character eligibility.

  remembered choices and weights remain. The outer window stays stable, and
  all actions remain reachable through minimum-size scrolling.

  Diagnostics stay in Game details. Ordinary setup has no redundant reminder.

  the player to finish opening tasks and wait for trader assignment before leaving.
