# New Player Random Start — Tech Demo

**7 Days to Die v3.3.0 · Random Player Start. By Bit Wrecked. Version 1.3.0.**

Start a fresh character somewhere different. Choose a biome, let the mod pick,
or set your own weights. A supported world can be new or already generated.

Extract this complete ZIP to a writable local folder. Close the game, open Steam
and run **START.bat** here. Choose your save's exact **Game Name** and settings,
then Apply. Acknowledge Settings Applied before Launch Game. You can configure
the name before its save exists. Check settings reads the current files without
changing your draft or creating a save.

For your first Random session, **complete the opening tasks and wait for the
Journey to Settlement trader marker before leaving**. You can visit the trader
later. Leaving earlier may send the quest to Pine Forest when you return.
The [full setup guide](customer/HistoricalRandomStart_1.3.0/README.md) explains
protection, upgrades, removal and the known Tech Demo limitation.

Use Windows PowerShell 5.1, local single-player and EAC disabled with the game's
supplied Harmony retained. The qualified build target is **V3.3.0 b17**.
Navezgane is supported; Random Gen worlds must be 8192 or larger. An already
played character stays in place. Configuration checks do not prove a runtime
landing, character eligibility or first trader assignment.
