# How this Tech Demo arrived here

The 1.3.0 Tech Demo is New Player Random Start for 7 Days to Die. Its runtime
keeps the established exact Game Name bridge, fresh-character eligibility,
placed-world landing, protection and first-trader behavior. The current round
updates the diagnostic identity and the native manager using the returned GUI
review. The [current DEV manifest](DEV-1.3.0-TECH-DEMO.md) records that scope;
the [setup foundation](../source/hrs_1.3.0_Tech_Demo/dev/BUILD_SETUP_FOUNDATION.md)
explains why settings can be prepared before the world or save exists.

The earlier public history is preserved byte for byte from frozen
1.2.7-qa.003. Read [how this was made](../history/HOW_THIS_WAS_MADE.md), the
original notes in `history/origins/`, and version records in `history/versions/`.
Their dates, older product names, source identities, results and unfinished work
belong to those rounds. The corresponding 1.2.7 source remains under
`source/hrs_1.2.7/`; current source is `source/hrs_1.3.0_Tech_Demo/`.
The prior public history and lore indexes are also retained unchanged in
`history/prior-public-index-1.2.7/`.

Previously public supporting records are retained unchanged under
`evidence/prior-1.2.7/`. Older contracts with different case counts and old
content manifests describe their original archive; they are not the contract
or inventory for this Tech Demo. Some original narrative links refer to DEV
records outside the public snapshot. Those original historical bytes remain
intact so the provenance can be checked.

[The evidence index](../evidence/README.md) distinguishes current bounded DEV
verification from prior observations. The new contract contains 46 independent
cases, all Pending when prepared. No earlier fixture or guided GUI review
completes a new candidate's gameplay, display, accessibility or newcomer QA.

Everyone receives the same complete public ZIP: product, source, native tools,
tests, full license, story and evidence. Publication follows fresh independent
QA and recorded release-owner approval of those exact bytes.
