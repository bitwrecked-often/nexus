# Bit Wrecked

“Preserve the state. Leave the trail. We walk from here.”

New Player Random Start grew from the idea that another starting place can
change the same familiar survival world. The project keeps its decisions,
failures and evidence alongside its source so the next person can understand
the work and build on it.

The [original project notes](../history/HOW_THIS_WAS_MADE.md) and
`history/origins/` preserve the earlier reasoning in its own words.
[History](HISTORY.md) explains the version boundaries, while
[the setup foundation](../source/hrs_1.3.0_Tech_Demo/dev/BUILD_SETUP_FOUNDATION.md)
records the exact-name mechanism that made setup before world creation possible.
Those records tell the project's story; current product behavior and known
limitations are described in [the customer guide](../README.md).

The icon is the owner's supplied Bit Wrecked artwork. The public archive
includes the full source license and the same development history for every
audience. It grants no rights to the game's assets or other third-party work.
