# Historical Random Start - Alpha 6 Method 0.0.1 — Framework Normalization Manifest

Status: Design-shell normalization complete; gameplay implementation not started

Source framework: Bit Wrecked blank working example and module-host evidence

New solution: `solutions/bit_wrecked_historical_random_start/`

Implementation authorized: Framework/design shell only

Release authorized: No

## Purpose

Provide the familiar clickable Bit Wrecked framework for the independent
Historical Random Start - Alpha 6 Method project without importing another mod's payload or
claiming unfinished behavior exists.

## Current Player-Facing Promise

The 0.0.1 BAT opens a branded, design-only Windows shell. The shell may select
and validate a game folder read-only. It cannot save world policy, install or
remove a helper, relocate a player, edit game files, or publish a package.

## Framework Recipe Decisions

| Recipe | Decision | Current adaptation |
| --- | --- | --- |
| Choose Game Folder | Retain | Read-only executable-folder recognition. |
| Inspect and Validate Current State | Adapt | Folder recognition only; policy/runtime validation is not implemented. |
| Select Settings | Defer | Standard/Random controls await approved runtime gates. |
| Install or Reinstall | Defer | Disabled; no payload exists. |
| Selective Uninstall | Defer | Disabled; no owned install exists. |
| Independent Cap/Stress Action | Omit | No equivalent requirement is approved. |
| Restore Saved Global State | Omit | No global game setting is owned. |
| Runtime and Persistent Logging | Retain cautiously | In-memory default; explicit local persistent log remains optional. |
| Confirmation and Local Assessment | Defer | Required when policy saving exists. |
| Validate, Package, and Release | Defer | No release authorization. |
| Disaster Recovery | Adapt | Documents and source remain local under the independent solution. |

## Active Ownership

The design shell owns only:

- `preview/START.bat`;
- `ui/p0159.ps1`;
- its local Bit Wrecked image asset;
- project documentation and evidence; and
- an optional persistent log path explicitly chosen by the user.

It owns no game, world, save, Harmony, XML, DLL, registry, service, scheduled
task, network, installation, or removal target.

## Normalization Result

- Active window and launcher identity name Historical Random Start - Alpha 6 Method.
- The tool visibly states that it is Phase 0A and payload-free.
- No Wasteland or weapon control row is presented.
- Spawn policy names are explanatory only; no control is actionable.
- Installation and removal remain disabled.
- The root BAT resolves the support tool relative to its own location.
- The shell requires no elevation, execution-policy bypass, encoded command,
  network access, or external installer.
