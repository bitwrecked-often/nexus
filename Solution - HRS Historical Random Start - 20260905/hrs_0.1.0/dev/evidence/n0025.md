# Phase 1 Observation Probe — First Compile Attempt

Date: 2026-08-20  
Decision: ABORTED; no artifact produced

## Authorization

The owner authorized compiling
`devprobe.dll` twice in the external build
stage for deterministic comparison and scanning. Copy and load were not
authorized.

## Pre-compile gate

The exact source manifest, compiler SHA-256, and all seven pinned reference
SHA-256 values revalidated successfully before invocation.

## Result

Both clean compiler invocations exited `1` with:

```text
fatal error CS2007: Unrecognized option: '/deterministic+'
```

No DLL, PDB, configuration file, or other output was produced. Both build
directories remain empty. Nothing was copied into `Mods` or loaded by the
game.

## Root cause

Although the installed .NET Framework compiler identifies its file/compiler
version as `4.8.9221.0`, its own help states that it supports language versions
only through C# 5. It does not expose the pinned `/deterministic+` switch and
also cannot satisfy the recipe's pinned `/langversion:7.3` requirement.

The restored August 14 recipe therefore combines a legacy .NET Framework
compiler path/hash with Roslyn-era switches that this executable cannot
accept. The compiler hash was correctly pinned, but capability was not proven.

## Stop condition

The build recipe requires abort on any compilation error and prohibits an
unreviewed compiler substitution. The next gate is a reviewed toolchain
amendment—most likely pinning the installed Roslyn compiler—followed by fresh
owner authorization for the amended exact build recipe.

## Amendment authorization

The owner authorized the exact installed Roslyn substitution on 2026-08-20.
The amended recipe pins both `dotnet.exe` and `csc.dll` by path and SHA-256,
continues to prohibit restore/MSBuild/implicit SDK references, and retains the
exact C# 7.3 deterministic compiler switches and game-supplied reference set.
