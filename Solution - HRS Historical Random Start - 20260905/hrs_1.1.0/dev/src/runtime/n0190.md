## Build sequence

1. Verify the game and relevant server processes are closed.
2. Resolve all roots and reject UNC, reparse, relative, live-root, or
   descendant-of-live-root targets.
3. Validate the approved target record and backup manifest.
4. Re-hash the compiler and every staged reference.
5. Inventory the exact source files and calculate a sorted source-tree manifest
   hash from relative path, byte length, and SHA-256.
6. Create one empty project-owned build directory beneath the approved external
   stage root.
7. Invoke the pinned compiler once with the exact source list above.
8. Treat every warning, error, unexpected output file, or missing deterministic
   option as a failed build.
9. Hash and stat the output DLL.
10. Perform source/static/string/dependency scans on that exact DLL.
11. Stage a fresh DEV payload directory and generate its sorted manifest hash.
12. Compare a second clean build. Investigate any byte difference before copy.

No copy into any game `Mods` folder occurs in the build sequence.

## Required build record

The record must include:

- approved target-record hash and backup-manifest hash;
- source revision or complete source-tree manifest hash;
- compiler path, version, size, and SHA-256;
- each reference name, size, version, origin, license status, and SHA-256;
- full compiler switch list and exit code;
- bounded warning/error output;
- output DLL name, size, timestamp, MVID, and SHA-256;
- exact staged payload inventory and aggregate manifest hash;
- first/second build comparison; and
- scanner names, versions, dates, results, and disposition.

## Build abort conditions

Abort without producing an approved artifact when:

- any path is unresolved, relative, network-based, reparse-backed, or inside
  the live installation;
- any target, compiler, source, or dependency hash differs;
- an unlisted source/reference/output appears;
- compilation warns or fails;
- a PDB, config, package, copied dependency, or other unapproved output appears;
- deterministic rebuilds differ without explanation;
- a scan finding is unresolved; or
- owner approval does not name the exact target and action.
