  private logs.

## Publication Gate

Before any Nexus or public copy:

1. select the exact intended payload rather than the whole development lane;
2. generate a file allowlist with sizes and SHA-256 hashes;
3. scan content and archive members for credentials and private paths;
4. compare the destination tree and review repository diff;
5. verify that generated, historical, probe, and private files are absent;
6. confirm license and source-distribution obligations; and
7. obtain explicit owner authorization for the specific copy/upload action.

Local Git tracking does not grant publication eligibility.
