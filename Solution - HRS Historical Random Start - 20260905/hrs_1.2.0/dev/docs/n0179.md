# Maintainers and Decisions

The Bit Wrecked project steward is the current scope owner and sole release
approver. Before publication, replace this role-only record with the approved
public account or organization identity; do not publish private contact data.

Material decisions belong in the manifest, plan, evidence, changelog, issue,
pull request, or release notes as appropriate. AI assistance does not confer
maintainer authority and cannot approve a release, waive a gate, claim a badge,
or accept provider terms for the owner.

Adding maintainers, changing license policy, publishing, signing a release, or
retiring a supported version requires an explicit steward decision.
