## Release landing transaction

For a permitted new Random game, the existing reservation and exactly-once
transaction now:

1. selects NG01 or NG02 with one game-owned RNG draw;
2. places the player and existing chunk observer at the catalog anchor;
3. waits for the containing chunk and then holds a two-second prime interval;
4. resolves terrain only after the chunk exists, using `GetTerrainHeight` and a
   bounded difference from the catalog elevation;
5. performs the second placement two metres above the safe terrain result;
6. requires three grounded samples near the approved X/Z and catalog elevation;
7. adopts the actual grounded prefab/terrain surface before completing the
   marker and starting the established nearest-trader route.

Any timeout, unsafe terrain, context change, or position mismatch follows the
existing reserved-marker failure and original-position restoration path. The
Standard branch, loaded-game observer, snow protection, starter quest, nearest
trader selection, result authority, and rollback design are unchanged.
