# Phase 1A Runtime Semantic Equality — Source Amendment

Date: 2026-08-20
Decision: Source/static/pure tests PASS; compile/stage/live/run NO-GO

The owner authorized a source-only in-memory semantic equality amendment. A
deterministic private digest is captured immediately before the one placement
call and again after final-position/safety verification but before Completed.

The digest covers:

- quest count, ID, state, phase, active-objective count, and optional-complete
  state;
- toolbelt and backpack slot order, item type/count, quality, use state,
  metadata integer, activation/ammo selection, and nested modifications;
- progression level, XP-to-next, XP deficit, skill points, XP gain, and player
  gamestage;
- health, stamina, food, and water; and
- active-buff name, stack multiplier, and flags, sorted by name.

Naturally ticking buff duration/update counters and buff instigator identity are
not included. The digest and underlying names/values are never logged or
persisted by the probe.

If the before/after digests differ, the probe emits only
`RELOC_SEMANTIC_CHANGED`, leaves Reserved, and stops before Completed. Equality
emits only `RELOC_SEMANTIC_UNCHANGED`, after which the existing guarded
Completed transition may run.

Static tests enforce semantic-before -> one SetPosition -> later position/safety
verification -> semantic-after -> Completed ordering. Relocation static tests,
seven semantic-harness tests, and the 22-case contract suite pass under
PowerShell 7 and Windows PowerShell 5.1.
