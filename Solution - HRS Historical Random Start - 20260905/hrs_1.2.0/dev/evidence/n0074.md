# Phase 1A Marker-Only Probe — First-Load Preflight

Date: 2026-08-20
Decision: Operational preflight PASS; test adequacy NO-GO; launch NO-GO

The first-load preflight is restricted to the exact installed and external
two-file payloads, pinned game assembly, EAC-disabled launcher setting, closed
game process, and absent `Navezgane / HRS_Phase1A_Test_001` target.

`tests/p0224.ps1` passed under PowerShell 7 and
Windows PowerShell 5.1. It confirmed the game is closed, both payload copies
are exact, the build fingerprint matches, the target save is absent, and the
launcher setting has EAC disabled.

During procedure review, a test-adequacy gap was found before launch. The
current probe writes Reserved and immediately reads it back on `NewGame`, but
`TargetGuard.IsApprovedLocalNewGame` rejects `LoadedGame` before
`MarkerStateStore.Read` runs. A later reload therefore emits only
`MARKER_TARGET_REJECTED` and cannot prove that the marker survived the normal
save/reload boundary.

Immediate read-back is not sufficient evidence for the prebuild packet's
required save/synchronization timing proof. The disposable target must not be
created until a narrowly amended marker-only source can observe—but never
write—the existing marker on the exact approved `LoadedGame` lane. The write
lane must remain exact local authoritative `NewGame` only.

No game was launched and no Phase 1A save was created. Amending source,
recompiling, replacing the installed owned DLL, or executing it requires new
explicit authorization.
