# Historical Random Start 1.0.0 release manifest

Release date: 2026-08-28  
Solution lane: `solutions/hrs_1.0.0`  
Game target: 7 Days to Die V3.2 (b9), Navezgane, local single-player  
Anti-cheat: disabled (`SkipWithAntiCheat=true`)

## Player features

- Portable PowerShell 5.1 manager launched through root `START.bat`.
- Exact-name Standard mode that leaves starting behavior unchanged.
- One-shot Random mode using twelve curated Navezgane survey anchors.
- Deferred placement and safe-landing verification after world chunks load.
- Optional suppression of the initial NG01 snow hazard only for the relocated
  character and selected game.
- Nearest opening-trader routing across Navezgane biomes.
- Vanilla quest lifecycle, rewards, trader interaction, and later progression
  remain intact.

## Trader implementation

V3.2 stores the starter quest on `EntityPlayerLocal`, normalizes its runtime ID
casing, and exposes some trader registries only transiently or server-side. The
release therefore:

1. observes the local player's journal for the full new-game session;
2. matches only `quest_whiteRiverCitizen1`, phase-one objective `trader`;
3. uses the five version-pinned trader placements and bounds authored in the
   installed Navezgane `prefabs.xml` and trader prefab XML files;
4. chooses the nearest placement deterministically by planar distance;
5. updates only that objective through native `ObjectiveGoto.SetLocation`;
6. records one-time Pending, Reserved, and Completed state on the character.

No base-game file is edited. Standard mode, unrelated saves, other quests, and
other worlds receive no trader mutation.
