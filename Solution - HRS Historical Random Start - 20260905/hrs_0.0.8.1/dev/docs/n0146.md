# Code of Conduct

Treat contributors, players, reviewers, and reporters with respect. Keep
disagreement technical and protect private information.

Harassment, threats, hate speech, doxxing, publishing private reports or logs,
misrepresenting another creator’s work, and encouraging unsafe use are not
acceptable. The project steward may remove material or restrict participation
to protect people or the project. Conduct concerns use the private route in
`SECURITY.md`.
