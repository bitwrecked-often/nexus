# Contributing

Historical Random Start - Alpha 6 Method is not yet accepting public contributions. This file
defines the gate for the future public repository.

- Read `SECURITY.md` before reporting anything sensitive.
- Do not submit game binaries, proprietary assets, saves, player data,
  credentials, private logs, or content without redistribution permission.
- Keep changes narrow and state the problem, intended behavior, files, write
  boundary, tests, dependencies, and rollback effect.
- Do not convert assumptions about game behavior into release claims.
- New dependencies require origin, version, license, hash, necessity, and risk
  review.
- Non-trivial changes require maintainer review and passing project checks.
- Generated artifacts must be traceable to reviewed source and build inputs.

Unless explicitly agreed otherwise before submission, contributions are made
under the project’s `GPL-3.0-or-later` license.
