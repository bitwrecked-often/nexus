# Historical Random-Start Factoid

Date: 2026-08-14
Scope: Historical player-facing wording for the Historical Random Start - Alpha 6 Method
preview

## Finding

The safest concise factoid is:

> Random first starts were part of the older Alpha 6-17.4 era. By Alpha 18,
> the same world name/seed could produce the same opening location.

This describes the historical behavior without claiming that every old build
used identical spawn logic or that the internal implementation changed in one
documented commit.

## Evidence

- The archived Alpha 6 notes record both “many new player starts spawn
  locations” and a spawn rule where, with Friendly Fire enabled, new players
  spawned away from one another “at a random spawn point.”
  [The Fun Pimps' Alpha 6 release notes](https://7daystodie.com/?p=1150)
- A November 2019 player report contrasts the Alpha 18 behavior with Alpha
  17.4, saying that Alpha 17.4 produced a randomized location for a new game
  while Alpha 18 repeatedly used the same location. The discussion also
  reports the same game name producing the same start for different players.
  [Steam discussion: same spawn spot every new game](https://steamcommunity.com/app/251570/discussions/1/1638675549007364681/)
- The Alpha 18 release notes confirm that Random World Generation was
  substantially overhauled, but they do not themselves state the exact player
  spawn-seeding change. Therefore the Alpha 18 transition wording remains an
  evidence-based historical synthesis, not a claim about an identified source
  code commit.
  [Alpha 18 patch notes](https://steamcommunity.com/app/251570/discussions/0/1629665087671514285)

## Product use

The factoid is informational only. It does not define the runtime
implementation. The current project still uses the proof-first contract:
native authored spawnpoints first, broader Random placement only behind later
gates, and no historical claim that the modern helper is an exact recreation
of an old build. The current product taxonomy is exactly Standard and Random.

current WordPress post ID `1150`. The site's old slug currently renders the
homepage, so the working official `?p=1150` permalink is used in the preview.
