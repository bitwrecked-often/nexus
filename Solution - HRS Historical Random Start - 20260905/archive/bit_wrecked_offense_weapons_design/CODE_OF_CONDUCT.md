# Code of Conduct

This project is a practical, volunteer-built modding framework. Treat people
with respect and keep discussion focused on the work.

Expected behavior includes good-faith technical discussion, clear disagreement
without personal attacks, respect for creator and player boundaries, and care
with security reports and private information.

Harassment, threats, hate speech, doxxing, sharing private material, deliberate
misrepresentation of another creator's work, or encouraging unsafe use of the
framework are not acceptable.

The repository owner may edit, remove, or close material that violates this
code, and may restrict participation when needed to protect contributors or
players. Report conduct concerns through the private contact path described in
`SECURITY.md`, using a minimal public request for a private channel if needed.
