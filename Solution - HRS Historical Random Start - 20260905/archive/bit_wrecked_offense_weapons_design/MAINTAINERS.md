# Maintainers and Decisions

Until this project has a public maintainer roster, the owner of the published
Bit Wrecked framework repository is the project steward and release approver.

The steward decides whether to accept contributions, publish releases, add a
maintainer, or retire a version. Decisions should be recorded in issues, pull
requests, release notes, or the changelog when they affect users.

No contributor receives authority over a gameplay payload merely by improving
the framework. Payload behavior remains the responsibility of the individual
mod's owner and its line-item evidence map.

Before public launch, replace this paragraph with the repository owner name or
organization and add any additional maintainers. Do not list private contact
information in the repository.
