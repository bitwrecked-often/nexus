5. Compatibility and multiplayer notes
6. Removal and recovery
7. License, source, and support information

## Search phrases

Use only phrases that are true for the release:

* `7 Days to Die [feature] mod`
* `[exact target] tuning`
* `XML modlet`
* `[supported game version]`
* `[specific player problem solved]`

Do not use misleading search terms such as “all weapons,” “universal,”
“overhaul,” “safe with every mod,” or “EAC compatible” unless the package has
evidence supporting those claims.

## Screenshot/video plan

| Asset | Shows | Must not imply |
|---|---|---|
| Cover image | Exact player promise | Features not included |
| GUI screenshot | Exact selection/validation state | Installation without confirmation |
| Gameplay capture | One validated effect | Universal behavior |
| Removal/validation capture | Reversibility | Save restoration unless tested |

## Publication checklist

* Title matches `ModInfo.xml` and package metadata.
* Description names exact supported behavior.
* Images show the current release.
* Archive names and hashes match the release record.
* License and source link are present.
* No claim exceeds the evidence in the technical manifest.
