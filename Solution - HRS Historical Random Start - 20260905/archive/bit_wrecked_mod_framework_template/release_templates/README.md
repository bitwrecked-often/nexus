# Bit Wrecked Release Templates

Copy these files into a new mod's active source only after the mod has a stable
identity and an evidence-backed payload. Replace every `[placeholder]`.

These are publishing and documentation templates, not proof that a new mod is
ready for release. The normal XML modlet remains the core package; optional GUI
tools must be documented separately and transparently.

Included templates:

* GPL-3.0-or-later license text
* Copyright and license notice
* Package metadata
* Player README and install guidance
* Legal and use notes
* Technical file manifest
* Release notes and changelog
* SEO/publishing copy
* Release checklist

Do not copy a prior mod's player-facing claims, compatibility promises,
screenshots, supported-target list, or release version without revalidating them
for the new mod.
