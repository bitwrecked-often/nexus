# Framework Archive — Wasteland Animal Reference Versions

This directory preserves copied Wasteland Animal Population Tuning version lanes
that arrived with the initial Offense Weapons framework clone.

They are reference and disaster-recovery material only. They are not Offense
Weapons versions and must not be built, packaged, or published as part of the
weapon solution.

## Active versus archived lanes

* Active Offense Weapons development lives only in `../versions/`.
* The current active lane is `../versions/0.0.1`.
* Animal-framework reference lanes are held under
  `wasteland_animal_reference_versions/`.

## Archive purpose

Use these copies only to compare framework behavior, recover a missing
reference file, or trace prior GUI/package conventions. The authoritative
animal solution remains the sibling
`7dtd_wasteland_animal_population_tuning_files` directory.
